{% comment %} Admin-only notification bell. Included from admin/base_site.html's usertools block override, so it appears on every Django admin page for staff users. Deliberately does NOT reuse notifications/_bell.html or its CSS/JS — that version depends on Bootstrap (data-bs-toggle, .dropdown-menu positioning), which Django admin doesn't load. Loading Bootstrap into admin just for this would risk clashing with Django's own admin CSS across every page (tables, forms, buttons, etc. all get restyled by Bootstrap's resets). This is a small, self-contained version instead: same context variables (unread_notification_count, recent_notifications — both already supplied globally by notifications.context_processors.notification_bell) and the same notifications:* URLs, but its own plain CSS/JS. unread_notification_count / recent_notifications are only ever non-empty for staff users (see notification_bell() in context_processors.py), so no extra permission check is needed here. {% endcomment %} {% load static %}
